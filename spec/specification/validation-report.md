## Exceptions

Static source inspection verifies the known screen/script and candidate-control references. Event-handler behavior, selector reachability and complete interactive state coverage require browser evidence. Dependency and link validation is not equivalent to complete semantic approval.

The common API/VPS envelopes, relational model, and default-deny semantics are precise proposals for review. Fixtures are versioned and describe fail and blocked conditions. Many tests still require exact approved schemas, executable adapter or browser inputs, and isolated test environments. The suite contains test specifications, not executable product code.
