# Phase 06 — Bootstrap, installation and onboarding

**Owner role**  Installation lead  
**Documentation status**  Drafted and structurally checked  
**Engineering status**  Proposed, with runtime evidence pending

## Purpose and scope

Transition preflight → installed/unclaimed → claiming → claimed → configured. Verify artifact and host eligibility before writes. Create initial administrator and consume the one-time claim atomically. Enrollment, recovery-code acknowledgment and IP/domain choice advance durable checkpoints. Resume after interruption. Follow the later onboarding notes for failure guidance placement, and keep server IP access until the custom hostname passes DNS and HTTPS checks.

## Contract and operational behavior

Inputs include supported host facts, artifact digest, initial admin identifier, address selection and DNS observations. Expose claim progress with next action and retry status. Claim token is a hashed secret reference, bound to installation and invalid after consumption or expiry. Persist checkpoints before reporting success. Failed custom hostname verification shows DNS guidance and safe retry, preserves current address, and records timestamp and observed evidence. Clean install, upgrade and uninstall are distinct workflows. Uninstall defaults to preserving managed customer data pending policy.

## Acceptance and test design

**REQ-P06-01 / AC-P06-01**. Two simultaneous claims yield one administrator and one consumption. Reboot at each checkpoint preserves claim ownership and resumes the required step. No automatic takeover after partial setup.

**TC-P06-01 · Procedure**. Race claims using the same bootstrap secret, crash after administrator commit, then fail DNS verification.

**Expected**. Exactly one privileged account, the second attempt denied, resume reaches address selection, server IP remains the usable current address.

**TC-P06-02 · Companion test**. Install an eligible image, claim once, enroll MFA and finish with a verified custom domain.

**Expected**. Setup is configured, correct administrator is present and the address serves trusted HTTPS.
