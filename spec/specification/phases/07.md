# Phase 07 — VPS agent and privileged execution model

**Owner role**  Host engineering lead  
**Documentation status**  Drafted and structurally checked  
**Engineering status**  Proposed, with runtime evidence pending

## Purpose and scope

A versioned typed operation envelope carries op ID, host, resource, action, desired generation, deadline and fencing token. Authenticate local or remote executor according to the approved topology. The privileged endpoint accepts enumerated verbs and validates scope, filesystem identity and args before effects. Persist a local operation journal. Reconcile uncertain outcomes against postconditions before retry. Shell and arbitrary unit names are excluded from generic execution.

## Contract and operational behavior

Intent includes verb version, installation and host identity, resource and owner revision, idempotency ID, fence, expiry and typed arguments. Result includes accepted/rejected/uncertain/verified, normalized error, effect summary and observed generation. Local executor must authenticate the peer and enforce host-level policy independently. The API and dispatcher enforce human membership and scoped product authorization. Remote executor, if approved, requires mutually authenticated peers and rotation. Helper rejects unregistered resource mappings, unsafe symlinks and unavailable adapters. Persist operation and fence before irreversible effects where possible, journal checkpoints around effect, and retain evidence until reconciliation.

## Acceptance and test design

**REQ-P07-01 / AC-P07-01**. Reject unknown verbs, wrong audience, expired grants, stale fences and changed replay payloads before dispatch. Identical replays return the recorded result or observed state. Audit dispatch and terminal outcomes.

**TC-P07-01 · Procedure**. Send wrong-host and stale-fence envelopes and drop the reply after a permitted config swap. Retry the same operation.

**Expected**. Rejected requests have zero effects. Exactly one swap occurs and the worker can observe its final generation.

**TC-P07-02 · Companion test**. Run a valid typed idempotent operation on its intended host and request observation.

**Expected**. Operation reports verified host generation and returns stable replay result.

## v2.0 audit correction

**AUD-07 · Critical.** The helper could be read as independently verifying human membership. The PRD separates peer enforcement and application authorization.

API/worker owns human authorization. Helper independently enforces peer identity, root-owned target scope, action allowlist and fencing. For an ambiguous action without observable postcondition, block automated retry and surface operator recovery.
