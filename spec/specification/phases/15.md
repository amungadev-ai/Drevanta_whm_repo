# Phase 15 — Developer workflows and deployment pipelines

**Owner role**  Developer platform lead  
**Documentation status**  Drafted and structurally checked  
**Engineering status**  Proposed, with runtime evidence pending

## Purpose and scope

Connect repositories through scoped installation grants, validate signed webhooks, pin source by commit, and build in isolated workers with short-lived credentials. Publish immutable artifacts with digest and provenance. Promote the same digest across environments. Production promotion binds authorized approver, target, digest and expiry. Lock target deployment and activate only after readiness. Rollback is a new deployment to a prior artifact and configuration, subject to schema compatibility. Keep historical release records immutable.

## Contract and operational behavior

Source connection contains provider installation ID, repository scope and signing configuration. Build records source revision, toolchain/base-image digests, recipe, worker isolation profile and output digest. Deployment records environment, immutable artifact, config revision, target fence, approval and previous known-good release. Cache keys include tenant and toolchain. Production approval invalidates with any changed bound input. Build credentials cannot reach deployment secrets. Reconcile rollback with data/schema compatibility separately.

## Acceptance and test design

**REQ-P15-01 / AC-P15-01**. Duplicate webhook deliveries cause one build per intent. Production reject-before-start applies when approval is stale, self-issued where separation is required, or bound to a different digest.

**TC-P15-01 · Procedure**. Replay a webhook, swap deployment digest after approval, and inject failed health during staging promotion.

**Expected**. One build. Changed digest is denied. Staging returns to last-known-good target and records failure.

**TC-P15-02 · Companion test**. Build pinned commit and promote its exact digest with a bound approval.

**Expected**. Environment activates one matching digest with provenance and verified readiness.
