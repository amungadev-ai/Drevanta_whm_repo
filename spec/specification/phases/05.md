# Phase 05 — Security architecture and threat model

**Owner role**  Security lead  
**Documentation status**  Drafted and structurally checked  
**Engineering status**  Proposed, with runtime evidence pending

## Purpose and scope

Treat browser and request data, repositories, archive contents, external callbacks, customer processes and adapter results as untrusted inputs. Constrain each trust crossing. Use deny-by-default authorization, secrets scoped by resource and purpose, step-up and audited intent for sensitive actions, and separate principals for panel, worker, runner and host helper. Isolate audit sinks and keep public diagnostics scrubbed.

## Contract and operational behavior

Threat/control/evidence pairs: session theft → revocation/rotation → revoked-cookie replay; confused deputy → scoped audience and generations → forged agent envelope; cross-tenant access → policy and query filters → seeded foreign IDs; archive traversal → under-root handles → symlink race; malicious build → isolated runner and restricted network → metadata/local target probes; provider spoofing → signature and replay rules → forged event; lockout → independent probe and watchdog → timed rollback; backup theft → scoped encryption and separate key recovery → ciphertext and isolated restore tests.

## Acceptance and test design

**REQ-P05-01 / AC-P05-01**. For each named trust boundary a representative exploit must be denied or contained with no lateral effect, and evidence shows correlation without credential disclosure.

**TC-P05-01 · Procedure**. Send a foreign resource ID, shell metacharacters in an action argument, and a callback targeting loopback. Search resulting audit for supplied secret canaries.

**Expected**. Requests denied, no host/provider effects, zero canary matches. Denial events carry correlation IDs.

**TC-P05-02 · Companion test**. Submit a valid scoped privileged action with a safe argument and trace through audit.

**Expected**. Effect occurs in the assigned boundary and audit correlates actor, target and outcome.
