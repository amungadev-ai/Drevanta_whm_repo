# Owner Audit Findings Register

Prepared for the owner's hands-on audit (docs/OWNER-ACCEPTANCE-TESTING.md).
**No findings are recorded yet** — this register ships empty by policy; the
owner records observations during/after the manual audit. Do not pre-fill.

## How to record a finding

Append one row per finding, and a matching detail block below.

| ID | Persona | Page/feature | Description | Expected | Actual | Severity | Repro steps | Requirement | Evidence | Resolution status | Regression verification |
| --- | --- | --- | --- | --- | --- | --- | --- | --- | --- | --- | --- |
| (awaiting owner audit) | | | | | | | | | | | |

Severity guide: HIGH (wrong/simulated results, security or data-integrity),
MEDIUM (functional gap vs the checklist), LOW (UX/polish). Expected-vs-actual
should reference the checklist item. Resolution status: OPEN / IN-PROGRESS /
FIXED (then regression verification notes the re-test).
